How it works

  1. 1Skin imageA close-up image of a mole or spot.
  2. 2PrepareResize to 224×224 pixels and adjust colours the same way as in training.
  3. 3AI modelResNet-50, an image-recognition network, trained on dermoscopy images.
  4. 4ScoreA number from 0 to 1. Above the decision line → "looks like melanoma".
  5. 5HeatmapGrad-CAM colours the area that pushed the score up.

What the AI learned from

HAM10000: 10,015 dermoscopy images of skin lesions, each with a diagnosis. Dermoscopy images are taken through a skin magnifier.

About 7,000 images were used for learning, and separate images were kept aside for testing. The examples on the "Try it" page come from the test set.

Licence: CC BY-NC 4.0 (non-commercial use). Works best on dermoscopy images; on ordinary phone photos it is less reliable.

What it is built with

  • ResNet-50 — pre-trained image model, then retrained for melanoma
  • PyTorch — runs the AI model
  • timm — library that provides ResNet-50
  • OpenCV — image resizing and the heatmap colours
  • Python web server + plain HTML/CSS/JavaScript — this page

Key findings

Primary model: standard ResNet-50, seed 0. Values come directly from the thesis results table; 95% intervals in brackets.
